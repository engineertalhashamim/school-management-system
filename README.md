# School Management System (SMS)

A web-based School Management System built for Karsaaz EBS Pvt. Ltd.

## Developers
- Talha — Backend Developer
- Moiz — Frontend Developer

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | Next.js (Latest) + Tailwind CSS |
| Backend | Express.js (Node.js) |
| Database | PostgreSQL |
| ORM | Prisma |
| Auth | JWT |
| Container | Docker + Docker Compose |

## Project Modules

- Authentication (Login / Logout)
- Student Management (CRUD)
- Teacher Management (CRUD)
- Class Management
- Attendance Management
- Dashboard
